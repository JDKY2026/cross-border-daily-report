# 跨境电商日报 Skill

## 职责边界

### 做什么
自动搜索近 24 小时的 Amazon 平台政策变动与跨境电商行业新闻，筛选去重后整理为结构化静态网页日报。

### 不做什么
- 不接入 Amazon Seller Central API 或任何私有数据源
- 不做竞品监控、价格追踪、销量分析
- 不做实时交互页面或仪表盘
- 不做自动定时触发
- 不做自有业务数据（广告/库存/订单）的整合

---

## 输入

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| trigger | string | 是 | 用户触发指令，如"生成今日日报" |
| date | string | 否 | 指定日期，格式 YYYY-MM-DD，默认当天 |
| focus_keywords | string[] | 否 | 额外关注的关键词，追加到默认搜索词中 |

> Agent 自主决定搜索关键词，无需用户提供额外输入。

---

## 处理步骤

### Step 1：生成搜索关键词

基于固定模板 + 日期，生成两组搜索词：

- **政策变动组**（至少 3 组搜索词）：
  - `Amazon policy change {date}`
  - `Amazon FBA fee update {date}`
  - `Amazon seller policy update {date}`

- **行业动态组**（至少 3 组搜索词）：
  - `cross-border ecommerce news {date}`
  - `Amazon seller news {date}`
  - `cross-border trade regulation {date}`

如用户提供 `focus_keywords`，追加到对应组别中。

### Step 2：执行搜索

对每组关键词调用联网搜索，获取原始结果。

要求：
- 每组关键词返回不超过 10 条结果
- 只保留近 7 天内的信息（防止过时内容混入）
- 记录每条结果的：标题、摘要、来源 URL、发布时间

### Step 3：筛选与去重

将 Step 2 的全部原始结果交由大模型处理：

1. **去重**：同一事件多次出现时，保留信息最完整的一条
2. **相关性筛选**：丢弃与"Amazon 政策变动"或"跨境电商行业"无关的结果
3. **分类**：将剩余结果归入「政策变动」或「行业动态」两个板块
4. **摘要**：对每条结果生成一句话摘要（不超过 80 字）
5. **排序**：每个板块内按重要性降序排列

### Step 4：生成 HTML 网页

基于筛选后的结构化数据，生成一份静态 HTML 页文。

页面结构：
```
┌─────────────────────────────────┐
│  跨境电商日报 | {date}          │
├─────────────────────────────────┤
│  📋 政策变动                     │
│  ┌─────────────────────────────┐│
│  │ 标题（可点击跳转来源）        ││
│  │ 摘要                        ││
│  │ 来源 · 时间                  ││
│  └─────────────────────────────┘│
│  ...（多条）                     │
├─────────────────────────────────┤
│  📰 行业动态                     │
│  ┌─────────────────────────────┐│
│  │ 标题（可点击跳转来源）        ││
│  │ 摘要                        ││
│  │ 来源 · 时间                  ││
│  └─────────────────────────────┘│
│  ...（多条）                     │
├─────────────────────────────────┤
│  生成时间：{timestamp}           │
└─────────────────────────────────┘
```

样式要求：
- 移动端友好，宽度自适应
- 中文字体优先，排版清晰
- 配色简洁专业，适合阅读

### Step 5：上传与交付

1. 将 HTML 文件保存到 `/tmp/daily-report-{date}.html`
2. 上传至对象存储（S3）
3. 返回可访问的 URL 链接

---

## 输出格式

### 最终交付物

一个可直接在浏览器打开的 URL，指向静态 HTML 日报页面。

### HTML 内数据结构

每个板块为一个数组，每条信息包含：

| 字段 | 类型 | 说明 |
|------|------|------|
| title | string | 标题 |
| summary | string | 一句话摘要（≤80 字） |
| source_url | string | 来源链接 |
| source_name | string | 来源名称 |
| publish_time | string | 发布时间 |

---

## 最终检查项

在输出 URL 之前，逐项确认：

- [ ] **搜索覆盖**：政策变动和行业动态两组关键词均已执行搜索
- [ ] **时效性**：所有信息均在近 7 天内
- [ ] **去重**：无同一事件重复出现
- [ ] **分类正确**：政策类归「政策变动」，行业类归「行业动态」，无错分
- [ ] **摘要质量**：每条摘要 ≤80 字，能独立传达关键信息
- [ ] **链接有效**：所有 source_url 可正常访问
- [ ] **页面可用**：HTML 在浏览器中正常渲染，无乱码、无排版错误
- [ ] **URL 可达**：返回的 URL 可直接打开，无需登录或额外权限
